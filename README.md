# Startup Funding Analysis

This project analyzes startup funding data to identify investment trends, funding patterns, top-performing startups, industries, cities, and major investors. The project uses **Python, Pandas, NumPy, Matplotlib, Streamlit, and MySQL** for data cleaning, analysis, visualization, and interactive dashboard development.

### Key Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Analysis of funding trends and startup industries
* Top startups and investors analysis
* City-wise and industry-wise funding analysis
* Interactive dashboard using Streamlit
* Data visualization for better business insights

### Technologies Used

**Python | Pandas | NumPy | Matplotlib | MySQL | Streamlit**

### Project Objective

The main objective is to transform raw startup funding data into meaningful insights that can help understand the startup ecosystem, investment patterns, and funding trends.
